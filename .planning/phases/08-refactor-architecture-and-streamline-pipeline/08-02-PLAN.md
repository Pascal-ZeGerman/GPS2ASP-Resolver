**Item 7 — Extract fallback helper in `signs/__init__.py`:**

Read the full `retrieve_signs()` function. The three fallback levels share the pattern: build query → fetch → check records → deduplicate → return `SignRetrievalSuccess | None`.

Extract an async helper:
```python
async def _try_query(
    client: SODAClient,
    on_var: str,
    from_var: str,
    to_var: str,
    side_of_street: str,
    on_street: str,
    from_street: str,
    to_street: str,
    soda_level: int,
) -> SignRetrievalSuccess | None:
    """Attempt one SODA query level. Returns SignRetrievalSuccess or None."""
    query = client.build_block_query(on_var, from_var, to_var, side_of_street)
    records = await client.fetch_signs(query)
    if not records:
        return None
    signs = _deduplicate(records)
    if not signs:
        return None
    return SignRetrievalSuccess(
        status="signs_found",
        signs=signs,
        on_street=on_street,
        from_street=from_street,
        to_street=to_street,
        side_of_street=side_of_street,
        soda_level=soda_level,
    )
```

Then replace each of the three repetitive blocks in `retrieve_signs()` with calls to `_try_query(...)`. Preserve the logging around each attempt (log before the call). The helper itself does NOT log — caller logs the attempt and result.
