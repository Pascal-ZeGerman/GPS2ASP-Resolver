**parser.py** -- Regex-based sign description parser. Follow project conventions: `from __future__ import annotations`, logging via `logging.getLogger("gps2asp.schedule.parser")`.

**Core functions:**

1. `parse_time_token(token: str) -> time` -- Parse a time token ("8:30AM", "1PM", "NOON", "MIDNIGHT") into `datetime.time`. Handle edge cases per research:
   - NOON -> time(12, 0)
   - MIDNIGHT -> time(0, 0)
   - 12PM -> time(12, 0) (noon, NOT midnight)
   - 12AM -> time(0, 0) (midnight)
   - Standard: strip AM/PM, convert to 24h. Use lookup-style for 12-hour boundary.
   - Raise ValueError for unparseable tokens.

2. `extract_days(text: str) -> list[ASPDay]` -- Extract days from the day portion of a sign description. Parse in this order (per research pitfall #5):
   - Check for EXCEPT clause first: `EXCEPT\s+(\w+DAY)` -> all 7 days minus excepted day
   - Check for dash range: `(\w+DAY)\s*-\s*(\w+DAY)` -> expand to full range (MONDAY-FRIDAY = Mon,Tue,Wed,Thu,Fri)
   - Otherwise: find all individual day names (MONDAY through SUNDAY) as whole words
   - Return sorted list of ASPDay values. Return empty list if no days found and no EXCEPT clause.

3. `parse_sign(sign_description: str) -> list[TimeWindow] | None` -- Main entry point. Parse a raw sign_description into a list of TimeWindow objects, or None on failure. Steps:
   - Strip prefix: match `^(?:NIGHT REGULATION\s*\(MOON & STAR(?:S)? SYMBOLS?\)\s*)?NO PARKING\s*\(SANITATION BROOM SYMBOL\)\s*(?:MOON & STARS?\s*\(SYMBOLS?\)\s*)?` (case-insensitive). If prefix does NOT match, return None (rejects template sign and non-standard formats).
   - Strip suffix: match `\s*(?:<-+>|--+>)\s*(?:\(SUPERSEDES\s+[^)]+\))?\s*$` (case-insensitive). Remove arrows and SUPERSEDES.
   - Extract time window: match `(MIDNIGHT|NOON|\d{1,2}(?::\d{2})?(?:AM|PM))\s*-\s*(MIDNIGHT|NOON|\d{1,2}(?::\d{2})?(?:AM|PM))` (case-insensitive). If no time found, return None (treat as unparseable).
   - Parse both time tokens via parse_time_token. If either raises ValueError, return None.
   - Validate: end_time > start_time (per research open question #3 -- all observed windows are same-day). If violated, return None.
   - Remove the time match from the remaining text, extract days from what's left.
   - If no days found and no EXCEPT clause found, return None (treat as unparseable per user decision: partial parses are failures).
   - Build list of TimeWindow objects: one per day, each with the same start/end times, source_sign set to the original sign_description.
   - Log at DEBUG level: parsed result. On failure, log at WARNING level with raw text and reason.

**tests/test_parser.py** -- Comprehensive unit tests. No network needed. Structure as test classes:

1. `TestParseTimeToken`:
   - Standard times: "8AM" -> time(8,0), "8:30AM" -> time(8,30), "1PM" -> time(13,0), "11:30AM" -> time(11,30)
   - Edge cases: "12PM" -> time(12,0), "12AM" -> time(0,0), "12:30PM" -> time(12,30)
   - Special tokens: "NOON" -> time(12,0), "MIDNIGHT" -> time(0,0)
   - Case insensitive: "noon", "midnight", "8am"
   - Failure: "GARBAGE" raises ValueError

2. `TestExtractDays`:
   - Single day: "TUESDAY" -> [TUESDAY]
   - Two days space-separated: "TUESDAY FRIDAY" -> [TUESDAY, FRIDAY]
   - Three days: "MONDAY WEDNESDAY FRIDAY" -> [MONDAY, WEDNESDAY, FRIDAY]
   - Dash range: "MONDAY-FRIDAY" -> [MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY]
   - EXCEPT SUNDAY: "EXCEPT SUNDAY" -> [MON, TUE, WED, THU, FRI, SAT]
   - No days found: "" -> []

3. `TestParseSign`:
   - Top 10 most common SODA patterns (from research catalog): "NO PARKING (SANITATION BROOM SYMBOL) TUESDAY FRIDAY 11:30AM-1PM <->" etc.
   - MOON & STARS: "NO PARKING (SANITATION BROOM SYMBOL) MOON & STARS (SYMBOLS) MONDAY THURSDAY MIDNIGHT-3AM <->"
   - EXCEPT SUNDAY: "NO PARKING (SANITATION BROOM SYMBOL) 8:30AM-9AM EXCEPT SUNDAY <->"
   - MONDAY-FRIDAY range: "NO PARKING (SANITATION BROOM SYMBOL) MONDAY-FRIDAY 8AM-9AM <->"
   - NIGHT REGULATION prefix: "NIGHT REGULATION (MOON & STAR SYMBOLS) NO PARKING (SANITATION BROOM SYMBOL) MOON & STARS (SYMBOLS) MONDAY THURSDAY 2AM-6AM <->"
   - SUPERSEDES suffix: "NO PARKING (SANITATION BROOM SYMBOL) TUESDAY FRIDAY 8AM-9:30AM <-> (SUPERSEDES SP-361C)"
   - NOON time: "NO PARKING (SANITATION BROOM SYMBOL) TUESDAY FRIDAY 10:30AM-NOON <->"
   - Template sign (must return None): `"NO PARKING <----> SANITATION BROOM (SYMBOL) XYY-XYY \"DAY\" THRU \"DAY\" (TIMES & DAYS TO BE SPECIFIED) (FOR CIRCULAR BUS SIGNS)"`
   - Non-standard prefix (must return None): "SOME RANDOM TEXT TUESDAY 8AM-9AM"

   - Time but no days and no EXCEPT (must return None)
   - Verify source_sign tracking: returned TimeWindow objects have source_sign == original input
